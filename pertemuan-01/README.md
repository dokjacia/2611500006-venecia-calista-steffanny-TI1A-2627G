# Pertemuan 1

Fungsi: dokumentasi capaian pembelajaran P1
1. Konsep Dasar Pemrograman Web : 
Pemrograman web merupakan proses pembuatan dan pengembangan aplikasi atau situs yang berjalan melalui internet
 
2. Arsitektur Klien-Peladen : 
• (client) : pihak yang meminta layanan atau sumber daya seperti aplikasi atau website
• peladen  (server) : program atau komputer yang menerima dan memproses permintaan tersebut dan mengirim respon kembali

3. HTTP Request dan Response : 
 HTTP Request : permintaan yang di kirim oleh klien kepada peladen melalui HTTP. HTTP request pesan yang dikirim oleh klien kepada peladen
 HTTP Response : respons yang dikirim peladen kepada klien sebagai jawaban atas HTTP request

4. HTML, CSS, JavaScript, PHP, MySQL :
- HTML digunakan untuk menyusun struktur dan konten halaman web (kerangka utama dalam halaman web).
- CSS digunakan untuk mengatur tampilan dan tata letak halaman web (desain dan estetika web).
- JavaScript digunakan untuk memberikan interaksi dan perilaku pada sisi klien(membuat web menjadi lebih hidup).
- PHP digunakan untuk melakukan pemrosesan dan logika aplikasi pada sisi peladen.
- MySQL digunakan untuk menyimpan dan mengelola data aplikasi(data base).

5. Hubungan Antarteknologi :
di mulai dari HTML Membentuk struktur halaman dan formulir data mahasiswa, CSS Mengatur tampilan formulir dan halaman
JavaScript Memberikan interaksi pada browser
PHP Memproses data tersebut dan meminta MySQL Menyimpan dan mengelola data mahasiswa
